## 一、单链表（25 分）

### 1.（15 分）就地逆置

**（a）代码（10 分）**

```c
ListNode *reverse(ListNode *head) {
    ListNode *prev = NULL;      // 已逆置部分的头
    ListNode *cur  = head;      // 当前处理的节点
    ListNode *next = NULL;      // 保存下一个
    while (cur != NULL) {
        next = cur->next;       // ① 先存
        cur->next = prev;       // ② 反转指针
        prev = cur;             // ③ prev 前移
        cur  = next;            // ④ cur 前移
    }
    return prev;                // 新头是 prev，不是 head
}
```

**得分点：**
- 三个指针初始化正确（3 分，`prev` 必须初始化为 `NULL`）
- **①先保存 next 再改指针**（4 分）——顺序反了链表就断，这是唯一的真考点
- 返回 `prev` 而不是 `head`（3 分）

**（b）逆置两次后的指针图（5 分）**

初始 `1→2→3→4→NULL`，循环 2 次后：

```
NULL ← 2 ← 1     3 → 4 → NULL
        ↑        ↑
       prev     cur  (next 指向 4)
```

**得分点：** `prev` 指向 2、`cur` 指向 3、1 的 next 已反转成 NULL、2 的 next 指向 1。（5 分，错一个方向扣 2 分）

**常见错法：**
- `prev = head` 初始化 → 0 分，会出现环
- 忘记保存 `next` 就改 `cur->next` → 0 分，链表断了
- 返回 `head` → 扣 3 分（这时 head 是尾节点）

### 2.（10 分）头插 vs 尾插

**（a）建出的链表（3 分）**

```
头插法：3 → 2 → 1 → NULL    （顺序相反！）
尾插法：1 → 2 → 3 → NULL
```

**（b）复杂度（3 分）：** 两种都是 **O(n)**，n 为元素个数。

**（c）为什么要尾指针（4 分）：**
尾插法每次要在**尾部**插入，没有尾指针就必须从表头遍历到尾，**每次插入 O(n)，建表总共 O(n²)**。维护尾指针后每次插入 O(1)，建表降到 O(n)。

**得分点：** 必须点出「没有尾指针 → 每次都要遍历 → O(n²)」。只说"方便"不给分。

## 二、双链表与循环链表（15 分）

### 3.（10 分）双链表插入

在 `p` 之后插入 `s`：

```c
s->next = p->next;      // ①
s->prev = p;            // ②
if (p->next != NULL) {  // ③ p 后面还有节点才需要改它的 prev
    p->next->prev = s;
}
p->next = s;            // ④
```

**一共改 4 个指针**（含条件分支里的那个）。

**得分点：**
- 4 个指针（4 分，漏一个扣 1 分）
- **顺序必须满足"先接 s 的两条，再改邻居"**（4 分）——先执行 `p->next = s` 会丢掉原来的后继
- 判断 `p->next` 是否为空（2 分）——p 是尾节点时漏这个判断会空指针

**常见错法：** 只写 3 个指针（漏 `p->next->prev`）→ 扣 4 分，这是最典型的错。

### 4.（5 分）循环链表结束条件

```
p == head        （或 p->next == head，取决于循环写法）
```

**为什么不能再用 NULL：** 循环链表的尾节点 next **指回头节点，不是 NULL**。所以永远遇不到 NULL，用 `p != NULL` 会**死循环**。

**得分点：** 条件 2 分 + "尾节点指向头"这个解释 3 分。

## 三、栈（25 分）

### 5.（10 分）括号匹配

`( [ ] { } )`：

```
读 (   栈：[ ( ]                     
读 [   栈：[ ( [ ]
读 ]   栈顶是 [ → 弹出               栈：[ ( ]
读 {   栈：[ ( { ]
读 }   栈顶是 { → 弹出               栈：[ ( ]
读 )   栈顶是 ( → 弹出               栈：[ ]
读完栈空 → 匹配成功
```

`( [ ) ]`：

```
读 (   栈：[ ( ]
读 [   栈：[ ( [ ]
读 )   栈顶是 [ ，与 ) 不匹配 → 失败
```

**失败点：第 3 个字符 `)` 处**，栈顶要求 `[`，实际遇到 `)`，**类型不匹配**。

**得分点：**
- 第一个成功的每步入栈出栈（4 分）
- 指出失败位置（3 分）和失败原因「类型不匹配」（3 分）

**常见错法：** 只说"括号不匹配"不说在哪一步 → 扣 3 分。

### 6.（15 分）中缀转后缀

输入：`3 + 4 * 2 - ( 1 + 5 )`

| 步骤 | 读入 | 栈 | 输出 |
|---|---|---|---|
| 1 | 3 | | 3 |
| 2 | + | + | 3 |
| 3 | 4 | + | 3 4 |
| 4 | * | + * | 3 4 |
| 5 | 2 | + * | 3 4 2 |
| 6 | - | **-**（弹出 * 和 +） | 3 4 2 * + |
| 7 | ( | - ( | 3 4 2 * + |
| 8 | 1 | - ( | 3 4 2 * + 1 |
| 9 | + | - ( + | 3 4 2 * + 1 |
| 10 | 5 | - ( + | 3 4 2 * + 1 5 |
| 11 | ) | **-**（弹出 + 和 (） | 3 4 2 * + 1 5 + |
| 12 | 结束 | 弹出 - | 3 4 2 * + 1 5 + **-** |

**答案：`3 4 2 * + 1 5 + -`**

**得分点：**
- 结果正确（6 分）
- **每一步栈和输出的变化过程完整**（9 分，错一步扣 1 分）

**常见错法：** 只写结果不写过程 → 最多 6 分。第 6 步漏弹出 `+` → 结果错。

## 四、队列（25 分）

### 7.（15 分）循环队列

**（a）条件（6 分）**

```
判空：front == rear
判满：(rear + 1) % MAX == front
元素个数：(rear - front + MAX) % MAX
```

**（b）为什么牺牲一个单元（9 分）**

因为**如果允许存满，判空和判满的条件会完全一样**——都是 `front == rear`。

- 队空时：`front == rear`（刚出队到空）
- 队满时：`rear` 绕一圈追上了 `front`，也是 `front == rear`

**两种情况无法区分**，所以必须有第三种状态：队列最多存 `MAX-1` 个元素，留一个空位。

**得分点：**
- 判空（3 分）、判满（3 分）
- "两种情况都会导致 front==rear，无法区分"（9 分，这是核心）

**常见错法：** 只写"为了防止溢出"→ 0 分，跟溢出没关系，是判定条件冲突。

### 8.（10 分）链队列删除最后一个元素

**必须把 `rear` 指针重新指回头节点（`rear = front`，或 `rear = head`）。**

不做会怎样：`rear` 变成**野指针**，指向已被释放的节点。下一次入队时 `rear->next = newnode` 写到已释放内存 → **未定义行为 / 崩溃**。

**得分点：** 指出"重置 rear"（6 分）+ 说明后果（4 分）。

## 五、复杂度（10 分）

### 9. 填表

| 操作 | 复杂度 | 理由（关键判据） |
|---|---|---|
| 按序号查找第 i 个 | **O(n)** | 链表无随机访问，必须从头走 i 步 |
| 头插 | **O(1)** | 只改头指针和两个 next |
| 尾插（无尾指针） | **O(n)** | 必须先遍历到尾部 |
| 尾插（有尾指针） | **O(1)** | 直接操作尾指针 |
| 删除**已知节点 p** | **O(1)** | 已有指针，`p->prev->next = p->next` 即可（单链表则需先找前驱，**是 O(n)**） |
| 删除**值为 x 的节点** | **O(n)** | 必须先查找 |

**得分点：** 每行 1.5 分（复杂度 + 理由各半）。**理由必须落到"要不要遍历"上，写"快/慢"不给分。**

**最后两行的坑：**
- 单链表「删除已知节点 p」严格说是 **O(n)**——因为要改前驱的 next，而单链表拿不到前驱，得从头找。
- 只有在**双链表**里，删除已知节点才是 O(1)。
- 如果答 O(1) 并说明是双链表 → 也算对，但要写清前提。
