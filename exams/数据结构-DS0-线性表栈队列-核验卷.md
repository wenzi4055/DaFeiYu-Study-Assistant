# DS0 重审查卷 · 线性表 / 栈 / 队列

**限时 40 分钟 · 100 分 · 过关线 80**

---

## 这份卷子为什么存在

你说「以前学过单链表的逆置和地址」，据此跳过了 ds0 直接学第四章。

**「以前学过」不是证据。** 三个月前看过的东西，现在可能只记得名词。这份卷子只做一件事：验证哪些是真会、哪些是需要补的。

**过关线定在 80，比 DS-1 的 90 低**——因为它验证的是"有没有基础"，不是"掌握到什么程度"。80 分以上说明基础在，可以往前学；不到 80 说明 ds0 得回头做，因为树和图的指针操作全建立在这上面。

**闭卷，不许查。写不出来的地方就空着，空着比瞎写有价值。**

## 一、单链表（25 分）

### 1.（15 分）就地逆置

把单链表 `1 → 2 → 3 → 4 → NULL` 就地逆置成 `4 → 3 → 2 → 1 → NULL`。

- (a) 写出完整代码（C 或 Python 伪代码均可）
- (b) **画出循环体执行 2 次之后**三个指针的指向图

### 2.（10 分）头插 vs 尾插

用头插法和尾插法分别建 `[1,2,3]` 的链表：

- (a) 两种方法建出来的链表分别长什么样
- (b) 时间复杂度各是多少
- (c) **为什么尾插法一般要多维护一个尾指针**

---

## 二、双链表与循环链表（15 分）

### 3.（10 分）双链表插入

在双链表节点 `p` 之后插入新节点 `s`，写出代码。

**关键：一共要改几个指针？少改一个会怎样？**

### 4.（5 分）循环链表的结束条件

普通单链表遍历结束的条件是 `p != NULL`。

**循环单链表遍历结束的条件是什么？为什么不能再用 NULL？**

---

## 三、栈（25 分）

### 5.（10 分）括号匹配

用栈判断括号是否匹配，写出 `( [ ] { } )` 和 `( [ ) ]` 的处理过程（每步的入栈/出栈）。

**哪个在什么时候失败，失败的原因是什么？**

### 6.（15 分）中缀转后缀

把中缀表达式 `3 + 4 * 2 - (1 + 5)` 转成后缀表达式。

**要求写出每一步栈和输出的变化过程**，只写答案不给分。

---

## 四、队列（25 分）

### 7.（15 分）循环队列

- (a) 写出判空条件和判满条件（设 `front` 指向队头，`rear` 指向队尾后一位，容量 `MAX`）
- (b) **为什么判满要牺牲一个存储单元？如果不牺牲，判空和判满会怎样冲突？**

### 8.（10 分）链队列的坑

链队列删除**最后一个元素**时，除了常规出队操作，还必须做什么？

**不做会怎样？**
