# DS-1 数组与广义表 · 答案与判分细则

阅卷人用。也用于自评——**先做完卷子再看**，先看即作废。

判分原则：**只看过程，不看结论。** 答案对但没推导 = 一半分；推导错但答案蒙对 = 0 分。

## 一、地址计算（24 分）

### 1.（8 分）`LOC(A[5][7])`，行优先

行优先的下标偏移是 `(i-1) × 列数 + (j-1)`，本题列数 = 10：

```
offset = (5-1)×10 + (7-1) = 40 + 6 = 46
LOC = 1000 + 46 × 4 = 1000 + 184 = 1184
```

**得分点**：偏移公式 4 分 / 乘字节 2 分 / 结果 2 分。
**常见错**：用了 8（行数）当列数 → 0 分；忘记 `(i-1)` 从 0 起算，写成 `5×10+7` → 0 分。

### 2.（8 分）`LOC(A[5][7])`，列优先

列优先把行下标变化最快，偏移是 `(j-1) × 行数 + (i-1)`，本题行数 = 8：

```
offset = (7-1)×8 + (5-1) = 48 + 4 = 52
LOC = 1000 + 52 × 4 = 1000 + 208 = 1208
```

**得分点**：认出列优先要换成"行数作乘数" 4 分 / 计算 2 分 / 结果 2 分。
**常见错**：直接照抄第 1 题的 1184 → 0 分（这两题就是用来分开两种遍历的）。

### 3.（8 分）三维数组

逐层拆：第 1 维步长 = 4×3 = 12，第 2 维步长 = 3，第 3 维步长 = 1。

```
offset = (i-1)×12 + (j-1)×3 + (k-1)

LOC(3,2,1) = 2000 + [2×12 + 1×3 + 0] × 2 = 2000 + 27×2 = 2054
LOC(4,3,2) = 2000 + [3×12 + 2×3 + 1] × 2 = 2000 + 43×2 = 2086
```

**得分点**：三个步长各自正确（4+2+2）。
**常见错**：把 `(k-1)` 的步长写成 3 或 4 → 至少错一个结果，扣 4 分。

## 二、特殊矩阵压缩（20 分）

### 4.（10 分）对称矩阵，存下三角含对角线

**(a) m = 10 × 11 / 2 = 55。**（等差数列 1+2+…+10）
写成 45（不含对角线）或 100 → (a) 全错，扣 3 分。

**(b) `A[8][5]`**：行号 ≥ 列号，本来就在下三角，直接套 `k = i(i-1)/2 + j`（i, j 从 1 开始）：

```
k = 8×7/2 + 5 = 28 + 5 = 33
```

**(c) `A[4][9]`**：行号 < 列号，在上三角，**必须先用对称性换成 `A[9][4]`**：

```
k = 9×8/2 + 4 = 36 + 4 = 40
```

**得分点**：(a) 3 分；(b) 3 分；(c) **4 分**，其中"做了对称转换"占 2 分。
**常见错**：(c) 直接把 i=4, j=9 代进去得 15 → 0 分。这题的唯一目的就是看你转不转身份。

### 5.（10 分）三对角矩阵

**(a) 通项公式（B 下标从 1 开始）：**

```
k = 2i + j - 2        (|i-j| ≤ 1)
```

推导：第 i 行之前共 `2 + 3(i-2) = 3i-4` 个元素（第 1 行 2 个，中间每行 3 个）；本行内该元素位于第 `j - (i-1) + 1` 个位置，两式相加化简即得。

**(b) n = 6，`A[4][3]`：`k = 2×4 + 3 - 2 = 9`。**
手工验证：行 1 占 B1—B2，行 2 占 B3—B5，行 3 占 B6—B8，行 4 从 B9 起，`A[4][3]` 是行 4 的第一个 → B9。✓

**(c) B 的元素个数 = 3n - 2 = 16。**

**得分点**：(a) 4 分；(b) 3 分；(c) 3 分。
**(c) 的常见错**：答 3n = 18，忘了首尾两行各只有 2 个元素。答 3n-1 也错。
**（b) 的常见错**：不验证、只用公式硬算成 4 或 10，说明没理解"行内起始列是 i-1 不是 1"。

> 注：不同教材对 B 的起始下标定义不同，会出现 `2i+j-2`、`2i+j-3`、`2i+j` 等写法。**判卷只认一条：你用哪个公式，就必须能用手工逐行数法验证出来。** 公式背错但验证过程正确 → 给一半分；公式背对但无法自证 → 也只给一半分。

## 三、广义表（34 分）

`A = (a, (b, c), ((d)))`，长度 3，元素依次是：原子 a、子表 (b,c)、子表 ((d))。

### 6.（6 分）`GetHead(A) = a`（原子 a，不是 (a)）
写成 `(a)` → 0 分。头是元素本身，不加括号。

### 7.（6 分）`GetTail(A) = ((b, c), ((d)))`
尾一定是**表**（去掉头剩下的元素整体加括号），长度 2。写成 `(b, c), ((d))` 少一层括号 → 扣 3 分。

### 8.（6 分）
- `Length(A) = 3`
- `Depth(A) = 3`

深度推导：`Depth(A) = 1 + max(各元素深度)`；a 是原子，深 0；`(b,c)` 深 1；`((d))` → `(d)` 深 1 → 故 `((d))` 深 2。所以 `1 + 2 = 3`。
**得分点**：长度 2 分 / 深度 4 分（必须写出哪个子表贡献最大深度）。

### 9.（8 分）`B = ((1,2), (3,(4,5)), 6)`
- (a) `GetTail(B) = ((3,(4,5)), 6)` → 取头 → **`(3, (4,5))`**
- (b) `GetHead(B) = (1,2)` → 取尾 → **`(2)`**

**得分点**：各 4 分。**常见错**：(b) 答 `2` —— 尾是表，答案必须带括号。(a) 答 `3` —— 漏了整层子表。

### 10.（8 分）`L = ((a), ((b),c), (d,e))`
- (a) `Depth(L) = 3`，最大深度来自子表 `((b),c)`：`(b)` 深 1 → `((b),c)` 深 2 → L 深 3。
- (b) `GetTail(L) = (((b),c), (d,e))` → `Length = 2`。

**得分点**：(a) 5 分（结论 2 + 指出来源子表 3）/ (b) 3 分。

## 四、概念与推导（22 分）

### 11.（6 分）
- 为什么 O(1)：数组元素**类型相同、大小固定、在内存中连续存放**，地址可由下标直接算出 `LOC = base + f(i,j) × L`，不需遍历。
- 与线性表的关系：**一维数组就是线性表（向量）**；二维数组可看作"每个元素是一个一维数组的线性表"——即线性表的推广/嵌套。
**得分点**：两小问各 3 分，缺一问扣 3 分。

### 12.（6 分）
- 表结点：`tag = 1`，存 `hp`（表头指针）、`tp`（表尾指针）。
- 原子结点：`tag = 0`，存 `data`（值）。
- 为什么必须有 `tag`：**同一指针位置指向的东西类型不定**——可能指向子表也可能指向原子。若用"指针是否为空"来区分，空表 `()` 和原子值 0/NULL 会撞车，且 `hp`/`tp` 的双指针布局与单值布局内存形态不同，运行期无法安全解释。
**得分点**：两类结点各 2 分 / tag 必要性 2 分。

### 13.（4 分）
- **三元组顺序表**：非零元素**位置稳定、不增删**，且以按行扫描为主（如矩阵转置、打印）。判据：改结构代价高，顺序存储省空间。
- **十字链表**：非零元素会**频繁插入删除或改变值**（如稀疏矩阵相加、动态累加）。判据：需要 O(1) 级定位行/列链并改链。
**得分点**：各 2 分。只写"一个省空间一个灵活"不给分——判据必须落到"是否增删"上。

### 14.（3 分）
`(())` ：**深度 2，长度 1**。
陷阱：空表 `()` 的深度是 **1**（有的教材记 0，若你的教材记 0 则本题答 1），长度 0。所以 `(())` 长度 1、深度在"空表深 1"体系下为 2。
**得分点**：长度 1 分 / 深度 1 分 / 说明空表深度的约定 1 分。

### 15.（3 分）
```
LOC(A[i][j]) = base + (i × n + j) × L
```
注意这里下标从 0 开始，所以是 `i×n + j` 而**不是** `(i-1)×n+(j-1)`。写成后者 → 0 分。
