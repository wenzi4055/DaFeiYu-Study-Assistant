## 二、五个按钮

| 按钮 | 什么时候按 | 按下后发生什么 |
|---|---|---|
| **✔ 过关** | 六条标准全部达标 | 计入完成度，自动跳到下一项未过关的任务 |
| **◐ 在途** | 开始学了，但还没达标 | **不计入完成度**，进度仍是 0。只是诚实标注 |
| **↺ 打回** | 发现之前过关过得太虚 | 退回待完成，百分比立刻掉下去，工时涨回去 |
| **▶ 计时** | 坐下来开始学的那一刻 | 按钮变 `■ 12:34` 实时走秒。再按一次弹出记录表单 |
| **AI 批改** | 想让模型按标准判你的作业 | 打开批改面板（见第五节） |

**「◐ 在途」是这个程序的核心。** 只有「过关/未过关」两态时，人会本能地把「看了但没懂」报成过关。给它一个只算 0 分的中间态，谎报的动机就消失了——你可以诚实地说「我在途」，而账本一分不给。

## 三、订立计划、设计目标（第一次用从这里开始）

点**第二行或第三行任意位置**，打开计划设置：

```
┌──────────────────────────────────────┐
│ 计划设置                              │
│ 改完点保存。今天想多做就调高每日配    │
│ 额，做不动就请假——请假的日子不算欠账。│
│                                      │
│ 每天  [60] 分钟  [30][45][60][90][120]│  ← 每日配额
│ 目标日 [2027-05-22]  格式 2027-05-22  │  ← 你的考试日期
│ 请假  [今天请假] [2026-11-05 ✕]       │  ← 点一下当天不算欠账
│                                      │
│ 剩 203 天，扣除请假 0 天 → 实际 203。  │
│ 还剩 174.6 小时，需 52 分钟/天。✓ 来得及│  ← 实时预览
│                                      │
│ [保存]                       [返回]   │
└──────────────────────────────────────┘
```

**三步设定：**

1. **目标日填考试日期** —— 这是整个程序的锚。不知道确切日期就先填一个大概的，之后能改
2. **每天配额** —— 先按 60 分钟试一周。做不动就调到 45，有余力就调到 90。**不要一上来定 120，定太高第三天就崩**
3. **看预览那行** —— 它会告诉你：这样下去赶不赶得上。出现 `⚠ 需 XX 分钟/天` 说明当前配额不够，两条路：调高配额，或者砍任务（比如先放弃哪一科）

**请假怎么用**：某天有事、病了、加班，点「今天请假」。这天不进「剩余学习日」，每日需求会自动重算，**不算你欠账**。

## 四、每天正常的操作流

```
坐下 → 点 ▶ 计时 → 学 → 学完点 ■ → 填两行 → 保存
                              ↓
                    「今天学到哪 / 卡在哪」
```

填完保存，详情区会变成 `已投入 1.2h / 预算 5.8h · 2 次学习记录`，账本里多一条 session。

**这条记录有两个用处：** 一是让你看见自己真花了多少时间，二是 AI 批改时会把它一起发给模型——所以模型能看出「你只看了视频、一次练习都没做」这种模式。

## 五、AI 批改（可选，不配也能用全部核心功能）

### 先配 Key（一次就够）

点标题栏 **API** → 选服务商 → 粘 Key → 点**测试连接** → 看到「连接正常」再点**保存**。

- **deepseek**：最便宜，一次批改约 ¥0.001，但**只能读文字**
- **glm-4v-flash**（智谱）：免费，**能读图**
- **qwen-vl-max**（通义）：有免费额度，**能读图**

要传手写推导的照片，必须选能读图的模型。程序会自己判断，不支持时会告诉你换哪个。

### 三种输入方式

| 方式 | 怎么用 | 适合 |
|---|---|---|
| **打字** | 直接写在框里 | 简短说明 |
| **Ctrl+V 粘图** | 截图后点框里按 Ctrl+V | 手写推导、代码截图 |
| **语音输入** | 点「语音输入」按钮，说完停一下 | 懒得打字时 |

语音走 Windows 离线引擎，不联网。**专业词容易听错**（「广义表」「行优先」），识别不准就按 `Win+H` 用系统语音输入。

### 提交后看什么

模型固定回四行：

```
【判定】🟢通过 / 🟡勉强 / 🔴打回
【漏洞】逐条列出没做到的地方
【依据】为什么这么判
【建议】通过 / 补做哪一项后再来
```

**AI 判通过也不会自动帮你过关。** 进度始终只由你点「✔ 过关」决定——批改是第二双眼睛，不是替你负责的人。

## 六、窗口操作

| 动作 | 效果 |
|---|---|
| 拖标题栏 | 移动窗口 |
| 双击标题栏 | 折叠成 32px 进度带（再双击展开） |
| 点 `—` | **最小化到任务栏**（不是折叠），从任务栏点回来 |

| 滚轮 | 任务多时滚动列表 / 验收标准 |

**找不到窗口时看任务栏**，它在那儿。

## 七、数据在哪、怎么备份

三个文件都在 **exe 同一个文件夹**里：

| 文件 | 内容 | 能不能删 |
|---|---|---|
| `tasks.json` | **任务池**：有哪些任务、几小时、验收标准、计划（起始日/目标日/每日配额/请假） | 删了会重新生成内置示例，**你的自定义全丢** |
| `dafeiyu_state.json` | **账本**：每项状态、学习记录 sessions | 删了进度归零 |
| `config.json` | **API 配置**：Key、模型、代理 | 删了要重配 Key |

**备份 = 把这三个文件复制走**。恢复 = 复制回来，重启程序。

程序目录下有个 `backup/` 文件夹，是打包好的快照（含 exe + 三个数据文件 + 恢复说明），解压即可换机使用。

## 八、改成你自己的东西

**换监督对象**（健身、毕设、写作）：改 `tasks.json` 的 `title`、`unit`、`tasks` 数组。字段说明见 [README](../README.md#改成你自己的任务池)。

**换监督语气**：`config.json` 的 `system_prompt` 留空用内置监工人格，写自己的就换。

**命令行**：

```bash
python dafeiyu.py --version    # 查版本
python dafeiyu.py --smoke      # 自检，0.8 秒退出
```

## 九、几个常见困惑

**「为什么我勾了在途，进度还是 0%？」**
就是这样设计的。在途 = 做了但没达标，不计分。

**「今天没学，明天会欠账吗？」**
会。第二行会变成 `欠 60 分钟 · 先补再往前`（橙色）。不想欠就请假。

**「我可以提前做明天的份吗？」**
可以。多做就多记，第二行会显示 `提前 XX 分钟`。

**「进度掉了怎么办？」**
那是你点「打回」的结果，正常。宁可现在掉，也别让它变成一个假的数字安慰你。

**「窗口不见了？」**
任务栏找。或者重新双击 exe，数据都在。
