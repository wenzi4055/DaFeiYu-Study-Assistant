## 二、四个按钮

| 按钮 | 什么时候按 | 效果 |
|---|---|---|
| **✔ 过关** | 验收标准全部达标 | 计入完成度，自动跳下一项 |
| **◐ 在途** | 开始学了但没达标 | **不计分**，只是诚实标注 |
| **↺ 打回** | 之前过关过得太虚 | 退回待完成，百分比掉下去 |
| **▶ 计时** | 坐下来开始学 | 变 `■ 12:34` 走秒，再按一次填记录 |

**只有「过关」计分。** 「在途」永远显示 0 —— 因为有这个中间态，你才不用把"看了但没懂"谎报成过关。

## 三、订立计划（第一次用先做这步）

点**第二行或第三行**，填两个数：

```
┌────────────────────────────────┐
│ 计划设置                        │
│ 只填两个数：每天花多久、什么时候考│
│                                │
│ 每天   [60] 分钟                │
│ 目标日 [2027-05-22]  如 2027-05-22│
│                                │
│ 剩 203 天，还剩 174.6 小时。    │  ← 实时算
│ 需要 52 分钟/天，你设的是 60 分钟│
│ ✓ 来得及                        │
│                                │
│ [保存]                  [返回]  │
└────────────────────────────────┘
```

- **目标日**：你的考试日期。整个程序的锚点
- **每天**：先填 60 分钟，试一周。做不动就调低，有余力就调高。**别一上来定 120，第三天必崩**
- 底部会算给你看：按你现在的配额，**赶不赶得上**

出现 `⚠ 不够` 说明 60 分钟不够，只有两条路：**调高配额，或者砍任务**。没有第三条。

## 四、每天怎么用

```
坐下 → 点 ▶ 计时 → 学 → 学完点 ■ → 填两行 → 保存
                        ↓
              「今天学到哪 / 卡在哪」
```

保存后详情区变成 `已投入 1.2h / 预算 5.8h · 2 次学习记录`。

**这两行记录唯一的作用：** 让你看见自己真花了多少时间。填「看完第一节，地址公式会推了，压缩矩阵还懵」这种就够，不用写作文。

## 五、窗口操作

| 动作 | 效果 |
|---|---|
| 拖标题栏 | 移动 |
| 双击标题栏 | 折叠成 32px 进度带 |
| 点 `—` | 最小化到任务栏（**从任务栏能找回**） |
| 点 `✕` | 关闭，数据已保存 |

## 六、数据在哪

三个文件，都在 **exe 同一个文件夹**：

| 文件 | 内容 |
|---|---|
| `tasks.json` | 任务池 + 计划设定（12 项、工时、目标日、每日配额） |
| `dafeiyu_state.json` | 账本（每项状态 + 学习记录） |
| `config.json` | 已废弃（v1.0.0 移除了 AI 功能，可删） |

**备份 = 复制这两个 json**。恢复 = 复制回来，重启程序。

## 七、几个困惑

**「勾了在途，进度还是 0%？」**
就是这样。在途 = 做了但没达标。

**「今天没学，会欠账吗？」**
会，第二行变橙色 `欠 60 分钟 · 先补再往前`。

**「可以提前做明天的份吗？」**
可以。多做就多记，显示 `提前 XX 分钟`。

**「窗口不见了？」**
任务栏找。找不到就重新双击 exe，数据都在。
