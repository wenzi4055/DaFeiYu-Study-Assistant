## 五、初学与重建的区别（这次踩的坑）

同一件事，两种估法差一倍：

| | 重建（复习） | 初学 |
|---|---|---|
| 起点 | 记得大概，只是不牢 | 看不懂，说不清 |
| 学段做什么 | 查漏补缺，重刷公式 | 从零建立概念，一次只通一件事 |
| 第一个验收 | 「限时测 90 分」 | 「能画出内存格子图」 |
| 卡住时怎么办 | 加快练习 | **停，回到上一层的「为什么」** |
| 工时 | 4h（原估） | 8h（实际） |

**判据很简单：能不能不看任何材料，把这个概念的「为什么」讲给一个外行听懂。** 讲不出，就是初学，不许按重建排。

## 六、这份估算怎么复核

```
单项工时 = 内容总量 ÷ 你的实际速度 × 练习系数(1.2~1.5) + 测试 1~2h
```

「实际速度」要自己测一次：拿一节录播计时看完，记下分钟数，再乘总节数。这一步 20 分钟，能让整张表从猜测变成你的真实数据。
