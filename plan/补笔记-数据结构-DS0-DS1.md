# 一、错题本（今天抓到的两个概念漏洞，最值钱）

## 错误 1：偏移 vs 第几个

```
A[7]，A[0] 在 2000，每元素 4 字节
❌ 2000 + 8×4 = 2032      ← 把「第 8 个」当偏移
✅ 2000 + 7×4 = 2028      ← 下标就是偏移
```

**规矩：下标从 0 开始时，偏移 = 下标本身，不需要任何加减。**

反证：如果偏移 = 下标+1，那 `A[0]` 的地址就变成 2004 了，但题目说它就是 2000。

**这一天内错了三次：1003、100+6×8-1=147、2032。三个都是同一个病。**

## 错误 2：深度 = 括号总数？不是

```
Z = ((), (a))

❌ 数括号：外层 1 对 + () 一对 + (a) 一对 = 3 → 答 3
✅ 展开看缩进：
   (
     (        ← 第 2 层
     ),
     (        ← 第 2 层
       a
     )
   )
   最深只到第 2 层 → 深度 2
```

**规矩：深度 = 展开成多行后，最大的缩进层数。不是数括号对数。**

`X = ((a))` 和 `Y = (a,(b,(c)))` 用错方法也能对，因为它们是「一条线套下来」。**只有分叉的 Z 能测出区别。**

## 错误 3：长度 = 原子个数？不是

```
Y = (a, (b, (c)))
❌ 数原子：a、b、c 三个 → 答 3
✅ 数最外层元素：a 和 (b,(c)) → 长度 2
```

**规矩：长度 = 最外层逗号个数 + 1。（空表长度 0）**

技巧：把内层括号全涂黑当一个块：
```
Y = ( a , █ )  → 2 个
Z = ( █ , █ )  → 2 个
X = (  █  )    → 1 个
```

# 二、广义表（课程标注的「本章难点」）

## 定义

```
LS = (a0, a1, …, an-1)
元素可以是原子（不可再分）或子表（又是广义表）
```

## 三条核心规则

```
空表 () 的深度 = 1
原子的深度   = 0
表的深度     = max{ 各元素深度 } + 1
长度         = 最外层元素个数（空表为 0）
```

## 课件例 4-5 标准答案

| 表 | 长度 | 深度 | 备注 |
|---|---|---|---|
| `A = ()` | 0 | **1** | 空表深度是 1，不是 0 |
| `B = (())` | 1 | **2** | 元素是空表，空表深 1，再加 1 |
| `C = (6,2)` | 2 | **1** | 全原子，0+1 |
| `D = ('a',(5,3,'x'))` | 2 | **2** | 最深子表 1，加 1 |
| `E = (C,D,A)` | 3 | **3** | 三个都是表名，D 最深（2），加 1 |
| `F = (C)` | 1 | **2** | |
| `G = (4,G)` | 2 | **∞** | 递归表，展开 `(4,(4,(4,…)))` |

## Head / Tail

```
Head = 第一个元素，原样取出（原子就是原子，子表就是子表）
Tail = 去掉第一个后，剩下的元素重新组成一个表（一定带括号）
```

| 表 | Head | Tail |
|---|---|---|
| `B = (())` | `()` | `()` |
| `C = (6,2)` | `6` | `(2)` |
| `E = (C,D,A)` | `C` | `(D,A)` |
| `F = (C)` | `C` | `()` |

**两条硬规矩：**
1. **空表没有 Head 和 Tail**
2. **Tail 永远是表**

# 三、数组与地址

## 行主序映射（p783 起）

```
map(i₁, i₂) = i₁ × u₂ + i₂        u₂ = 列数
```

原因：第 i₁ 行之前有 i₁ 整行，每行 u₂ 列。

## 列主序（你没学的，补上）

```
map(i₁, i₂) = i₂ × u₁ + i₁        u₁ = 行数
```

**记忆：按行铺就乘列数，按列铺就乘行数。乘的那个数永远是「一排有几个」。**

## 地址计算的完整链条

```
行列下标 → 算序号（i×列数+j）→ 乘每格字节数 → 加 base → 地址
```

**举例**：3×6 数组，base=1000，每元素 4 字节

```
a[1][0] → 序号 1×6+0 = 6  → 1000 + 6×4  = 1024
a[2][5] → 序号 2×6+5 = 17 → 1000 + 17×4 = 1068
```

# 四、矩阵压缩存储（四种公式）

**全部按「下标从 0 开始」。**

| 矩阵 | 公式 | 容量 |
|---|---|---|
| 下三角 | `i(i+1)/2 + j` | `n(n+1)/2` |
| 上三角 | `i(2n-i+1)/2 + (j-i)` | `n(n+1)/2` |
| 对称矩阵 | `j≤i` 用下三角；`j>i` 交换 i、j 后套 | `n(n+1)/2` |
| 三对角 | `2i + j` | `3n - 2` |

## 四个公式的共同骨架

```
k = （前面有多少个元素） + （本行内前面有多少个）
```

**记住骨架，四个都能现场推，不用背。**

## 上三角为什么最容易错

**行内偏移是 `j-i`，不是 `j`。** 因为第 i 行从第 i 列才开始有元素。

## 对称矩阵的完整取值流程

```c
if (j <= i)   k = i(i+1)/2 + j      // 下三角，直接查
else          k = j(j+1)/2 + i      // 上三角，交换身份再查
```

交换后必须满足「行号 ≥ 列号」，才能套下三角公式。

## 下标体系：0 开始 vs 1 开始

```
i₀ = i₁ - 1
```

**两道题做之前先圈两件事：**
1. 矩阵 `a[i][j]` 的 i、j 从几开始
2. 压缩数组 `B[k]` 的 k 从几开始

| | 0 开始 | 1 开始 |
|---|---|---|
| 下三角 | `i(i+1)/2 + j` | `i(i-1)/2 + j` |
| 三对角 | `2i + j` | `2i + j - 2` |

# 五、DS0 要点速查（线性表/栈/队列）

## 单链表

```c
// 就地逆置（四步，顺序不能乱）
next = cur->next;      // ① 先存
cur->next = prev;      // ② 反转
prev = cur;            // ③ prev 前移
cur  = next;           // ④ cur 前移
// 返回 prev，不是 head
```

**尾插法为什么要尾指针**：没有的话每次都要从头遍历到尾，建表变 O(n²)。

## 双链表插入（**4 个指针**）

```c
s->prev = p;              // ①
s->next = p->next;        // ②
if (p->next) p->next->prev = s;   // ③ 别漏这个
p->next = s;              // ④
```

**漏掉 ③ 是最典型的错。**

## 循环链表

```
遍历结束条件：p == head（不是 p != NULL）
原因：尾节点的 next 指回头节点，永远遇不到 NULL，用 NULL 判会死循环
```

## 循环队列

```
判空：front == rear
判满：(rear + 1) % MAX == front
元素个数：(rear - front + MAX) % MAX
```

**为什么牺牲一个单元**：如果允许存满，判空和判满都是 `front == rear`，两种情况无法区分。

## 链队列删除最后一个元素

**必须重置 `rear = front`（或 `rear = head`）。** 不重置的话 `rear` 变野指针，下次入队写到已释放内存。

## 复杂度表

| 操作 | 复杂度 | 理由 |
|---|---|---|
| 单链表按序号查找 | O(n) | 必须从头走 |
| 头插 | O(1) | 只改头指针 |
| 尾插（无尾指针） | O(n) | 要遍历到尾 |
| 尾插（有尾指针） | O(1) | 直接操作 |
| 删已知节点 p（单链表） | **O(n)** | 要改前驱的 next，得从头找 |
| 删已知节点 p（双链表） | O(1) | 有 prev 指针 |
| 删值为 x 的节点 | O(n) | 必须先查找 |

**最后两行的坑：单链表里删「已知节点」也是 O(n)，只有双链表才是 O(1)。**

## 卡特兰数（出栈序列个数）

```
Cn = C(2n, n) / (n+1)

n=3 → C(6,3)/4 = 20/4 = 5
n=4 → C(8,4)/5 = 70/5 = 14
```

**最容易漏的是最后除以 (n+1)。**
